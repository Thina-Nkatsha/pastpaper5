STUDENT REPORT JAVA PROGRAM

Open useStudent.java in IntelliJ IDEA and run the main method.

The program asks for:
- Student number
- Test result
- Assignment result
- Exam result

The weighting is:
- Test = 25%
- Assignment = 25%
- Exam = 50%

The final result is calculated using:
(Test x 25%) + (Assignment x 25%) + (Exam x 50%)
